# Security

Every lab here is intentionally vulnerable by design and meant to run
on your own machine. If you find a problem that could affect someone
running a lab as documented — for example a lab that reaches outside
the sandbox it describes — please report it privately through
[GitHub's private vulnerability reporting](../../security/advisories/new)
rather than a public issue.

Questions and bugs in the lab instructions belong in a normal issue.
Never paste secrets, tokens, or private data into an issue.
