# GitOps that survives bad days: Flux + Helm on your laptop

This lab builds a hands-on GitOps pipeline using Flux and Helm on a local Kubernetes cluster (kind) with Gitea as the git remote. You'll learn how Flux continuously reconciles your desired state from git, manage secrets with SOPS, perform safe deployments through Helm, detect and correct drift, implement automatic rollback on failed upgrades, and recover when retries are exhausted—all without leaving your machine.

Full instructions come with the final lab step.
